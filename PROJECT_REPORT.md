# Student Performance Management System

## 1. Introduction

The Student Performance Management System is a Java-based command-line application developed to manage and monitor student academic information. The system provides a simple way to store student details, marks, and attendance in one place.

It reduces the need for manual record keeping and makes it easier to search, update, and manage student information. The system also calculates percentages and grades, analyzes overall performance, and generates a student performance report.

## 2. Project Overview

The project is divided into different modules to handle specific tasks.

### Student Management

This module allows the user to add, view, search, update, and delete student details.

### Marks Management

This module stores marks for Mathematics, Java, and Operating Systems. It calculates total marks, percentage, and grade.

### Attendance Management

This module stores attendance records and calculates the attendance percentage and eligibility status.

### Performance Analysis

This module analyzes a student's marks and attendance and classifies the overall performance as Excellent, Good, Average, or Needs Improvement.

### Report Generation

This module generates a complete performance report containing student details, marks, percentage, grade, attendance, and overall performance.

### File Management

Student, marks, and attendance data are stored in text files so that the information can be loaded when the program is started again.

## 5. System Workflow

The user starts the application and selects an option from the main menu. Depending on the selected option, the system manages student details, marks, or attendance.

The entered information is validated before being processed. The data is stored in text files and can later be searched or used for performance analysis.

The system can also generate a complete performance report for a selected student.

## 6. Main Features

- Add and manage student details
- Add and manage marks
- Add and manage attendance
- Calculate percentage and grades
- Analyze student performance
- Generate student reports
- Validate user input
- Store data using files

## 7. Conclusion

The Student Performance Management System provides a simple and organized way to manage student academic records. The project helped in applying Java and Object-Oriented Programming concepts to a practical problem.

The system can be further improved by adding a graphical interface, database connectivity, login functionality, and graphical performance reports.
